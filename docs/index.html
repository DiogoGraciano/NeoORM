Princípios de projeto

Um model descreve a tabela; ele não abre conexão, não representa linha e não executa consulta. A biblioteca separa schema, acesso a dados e dados iniciais para que cada mudança seja rastreável e verificável.

Suporte: MySQL e PostgreSQL. A API preserva o mesmo contrato de resultados nos dois dialetos sempre que possível; onde o SQL diverge, o compilador cuida da diferença.
